加一个暗色模式切换按钮

已添加暗色模式切换。核心实现：

javascript 
const toggle = document.querySelector('.theme-toggle');
toggle.addEventListener('click', () => {
  document.body.classList.toggle('dark');
  localStorage.setItem('theme',
    document.body.classList.contains('dark') ? 'dark' : 'light'
  );
});

点击导航栏右侧的 🌙 按钮即可切换。
